# ReRT-EQD2
ReRT EQD2: offline web app that calculates cumulative EQD2 for re-irradiation. Covers head &amp; neck, CNS, cranial SRS/SRT, thorax, abdomen and pelvis, for up to three courses, with referenced limits, recovery, DVH import and a PDF report. Designed by Ali Eid, Medical Physics Expert (EACMPE – Ireland). Not a medical device.
